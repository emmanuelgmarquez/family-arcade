File names and manifest format

Name sprite files by slot number: 001-front.png, 001-back.png, 002-front.png and so on. Folders inside a ZIP are fine, and a manifest.json inside the ZIP is read too. Sprites keep their transparency, solid backgrounds are removed, and pixels are scaled by whole steps so they stay sharp. 64×64 works best for both sides.

The manifest is JSON with a creatures list. Each entry can have number, name, types, stats (HP, Attack, Defense, Sp. Atk, Sp. Def, Speed, or five values with one Special), moves as [level, moveId] pairs, evolutions as {"to": 2, "level": 16}, {"to": 3, "item": "stoneId"} or {"to": 4, "trade": true}, description, catchRate, expYield, legendary and habitats. Top-level types, chart, moves, items, starters, gift, legendary and typeMap are optional.
